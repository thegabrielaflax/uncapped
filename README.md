# Uncapped

Uncapped by Pivot School is a portfolio career builder for Claude Desktop. It helps you find what you could get paid for, choose a first offer to test, plan your first 10 customers and build a Substack strategy for the same offer.

It runs in the Code tab of Claude Desktop, on your own Claude plan. Your work is saved as files in your Uncapped folder, and updates never change it.

Open your Uncapped folder in the Code tab, start a chat and send "Open Uncapped". The panel opens beside the chat; type /uncapped if it doesn't.
